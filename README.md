# 记账工具（bookkeeper）

个人记账命令行工具，包含两个脚本：

- `assets.py` —— 记录和管理个人**资产现值**快照
- `invest.py` —— **基金买卖事件**记账，计算盈亏与年化收益率

两者数据相互独立（`assets.json` / `investments.json`）。

---

# 资产现值记账（assets.py）

记录和管理个人资产快照的命令行工具。

## 数据文件

资产数据存储在 `assets.json` 中，包含账户定义和按日期的余额快照。

## 命令

### record

录入当前日期的资产快照。每个账户显示上次余额作为默认值，直接回车沿用，输入 `q` 取消不保存。

```
uv run assets.py record
```

### list

查看资产总表，默认只显示最近余额不为 0 的活跃账户。

```
uv run assets.py list
uv run assets.py list --full       # 显示所有账户（含余额为 0 的）
uv run assets.py list --by-type    # 按资产类别汇总（银行/支付/货币基金/基金）
uv run assets.py list --by-org     # 按机构/平台汇总（每个银行/平台各一列）
```

### add-account

添加新账户（如新购入的基金）。

```
uv run assets.py add-account
```

## 数据结构

### 账户

每个账户有 `id`、`name`、`type`、`org` 字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| id | 唯一标识，英文 | `alifund_018610` |
| name | 显示名称 | `支付宝基金-018610` |
| type | 资产类别 | `bank`, `fund`, `money_market`, `payment` |
| org | 机构/平台（中文，新机构直接新增） | `工商银行`, `芜湖扬子银行`, `支付宝`, `微信` |

`org` 表示钱存放在哪家机构，多个账户可同属一个机构（如余额宝、支付宝基金都归 `支付宝`）。

### 快照

每次 `record` 生成一条快照，记录所有账户在当日的余额。

```json
{
  "accounts": [
    { "id": "abc", "name": "农业银行", "type": "bank", "org": "农业银行" }
  ],
  "snapshots": [
    {
      "date": "2025-05-11",
      "balances": { "abc": 988, "alipay": 1108 },
      "total": 45640
    }
  ]
}
```

# 基金投资记账（invest.py）

记录基金**买卖事件**，并计算当前持仓盈亏与 XIRR 年化收益率。当前净值通过东财接口**实时获取**，无需维护本地数据文件，也不依赖 `fetch_fund.py` / `utils.py`。

仅依赖 `rich`（表格渲染）与 Python 标准库。

## 命令

### record

交互式录入一笔买入或卖出事件（任意输入处输入 `q` 取消，不保存）。

```
uv run invest.py record
```

- **买入**填申购金额，`份额 = 金额 / 单位净值`
- **卖出**填赎回份额（按份额赎回），`毛额 = 份额 × 单位净值`
- **手续费**支持直接填金额，或填带 `%` 的费率（按金额折算）
  - 买入：申购费**另算计入成本**，不从申购金额/份额中扣除
  - 卖出：赎回费从净到账中扣除
- 卖出会校验**不超持仓**；卖出份额与 4 位小数显示有含入差时视为清仓（防止浮点误报）

### list

查看持仓盈亏报表：份额 / 成本 / 市值 / 总盈亏 / 总盈亏% / 年化%，末尾为组合合计。

```
uv run invest.py list
```

- `市值 = 实时最新净值 × 当前份额`
- **年化 = XIRR 资金加权年化收益率**，单基金与组合统一以「最新净值日」为末笔清盘日
- **已清仓（份额为 0）的基金不再请求网站数据**，即使该基金已无法查询也不会卡住报表

### events

列出全部原始事件（含编号，供 `del` 使用）。

```
uv run invest.py events
```

### del

删除一条事件（需二次确认）。

```
uv run invest.py del <编号>
```

## 事件数据结构（investments.json）

```json
{
  "events": [
    { "date": "2026-07-22", "code": "003015", "action": "buy",
      "price": 2.1525, "amount": 9990.01, "fee": 9.99, "note": "" },
    { "date": "2026-08-07", "code": "018610", "action": "sell",
      "price": 2.166, "shares": 900.0, "fee": 1.9, "note": "" }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `action` | `buy` 买入 / `sell` 卖出 |
| `price` | 成交单位净值 |
| `amount` | 仅买入：申购金额 |
| `shares` | 仅卖出：赎回份额 |
| `fee` | 手续费：买入=申购费，卖出=赎回费 |
| `note` | 可选备注 |

## 记账口径

| 项目 | 计算 |
|---|---|
| 买入份额 | `申购金额 / 单位净值` |
| 买入成本 | `申购金额 + 申购费` |
| 卖出到账 | `赎回份额 × 单位净值 − 赎回费` |
| 已实现盈亏 | 卖出净到账 − 卖出份额对应均价成本 |
| 未实现盈亏 | `现价 × 当前份额 − 剩余成本` |
| 总盈亏 | `市值 + 已撤回 − 总投入`（≡ 已实现 + 未实现）|
| 年化收益率 | XIRR 资金加权年化，单基金与组合统一锚定最新净值日 |
